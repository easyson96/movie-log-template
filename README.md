# Movie Log Template

영화 감상 직후의 생각과 감정을 빠르게 기록하기 위한 마크다운 템플릿입니다.  
Obsidian에서 쓰기 좋은 상세 템플릿과, 공유용으로 간결한 라이트 템플릿을 함께 제공합니다.

---

## Overview

- 감상 직후 떠오르는 인상과 메모를 빠르게 남기기 위한 고정 양식
- 장기적으로 영화 감상 기록을 축적·검색하기 쉬운 형태를 목표로 합니다.
- 마크다운을 지원하는 에디터(Obsidian, VS Code, 일반 텍스트 에디터 등)에서 사용할 수 있습니다.

---

## Files

> 실제 저장소의 파일명에 맞게 수정해서 사용해 주세요.

- movie-log_template.md  
  - 개인 기록용 상세 템플릿
  - 감상 직후 메모부터 기본 정보, 태그, 별점까지 포함한 구조

- movie-log_template_lite.md  
  - 공유·협업용 라이트 템플릿
  - 한 줄 요약, 기본 정보, 간단한 메모 위주로 구성

---

## How to Use

### Obsidian에서 사용

1. 이 저장소를 클론하거나, 필요한 템플릿 파일을 개별 다운로드합니다.
2. Obsidian Vault 안에서 템플릿을 둘 폴더를 하나 정합니다.  
   예: [BACKTICK]Templates/Movie[BACKTICK]
3. movie-log_template.md 파일을 해당 폴더에 복사합니다.
4. Obsidian의 템플릿 관련 기능(Templater 플러그인 또는 Core Templates)을 통해,
   - 새 노트 생성 시 이 템플릿을 불러오거나
   - 명령 팔레트/단축키로 템플릿을 삽입해서 사용합니다.
5. 영화를 본 직후, 새 노트를 만들고 템플릿을 삽입한 뒤 각 항목을 채워 넣습니다.

### 라이트 템플릿 사용

1. movie-log_template_lite.md 내용을 복사합니다.
2. Notion, Google Docs, 사내 문서 시스템 등 원하는 곳에 붙여 넣습니다.
3. 모임/팀에서 합의한 항목에 맞게 일부 필드를 추가하거나 삭제해 사용할 수 있습니다.
